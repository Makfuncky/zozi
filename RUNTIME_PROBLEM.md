> **Scope.** Runtime behaviour of the three deployables launched by `.\run_zozi.bat`
> (`backend`, `frontend/web_app`, `frontend/mobile_app`), checked against the two canonical
> benchmark documents `_most_imp_docx/ARCHITECTURE_STACK.md` (structure + 325 laws) and
> `_most_imp_docx/TECHNOLOGY_STACK.md` (versions, SDKs, env contract). Both documents were
> read end-to-end before any code was modified.
>
> **Correction notice.** This document supersedes all earlier `RUNTIME_PROBLEM.md` versions.
> Previous reports contained factual errors discovered during direct code inspection.
> All findings below are verified against the actual codebase and benchmark docs.
>
> **Method.** (1) Read benchmark files from top to bottom. (2) Read actual source files
> for every claim. (3) Cross-checked earlier sub-agent reports against live code.
> (4) Researched correct package versions, import paths, and canonical patterns.
>
> **Final state.** Backend cannot start in development mode. Web app cannot start.
> Mobile app cannot start. Docker build has critical failures. Tests pass in test mode
> only because `APP_ENV=test` bypasses the dev validator.
