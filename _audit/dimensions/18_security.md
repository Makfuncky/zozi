## Over all

### Problem(s)
1. Payment gateway credentials (`secret_key`, `webhook_secret`) are stored in plaintext in the `finance.payment_gateway_connections` table, violating PCI-DSS Requirement 3 and the platform's own architecture stack which mandates AES-256-GCM encryption via `field_encryption.py`.
2. Multiple SQL injection vulnerabilities exist via f-string interpolation in migration scripts (`2026_07_29_20_30`), key rotation utility (`infrastructure/security/key_rotation.py`), and analytics query service (`command_center_query_service.py`).
3. SSRF vulnerabilities exist in multiple outbound HTTP clients (security/watchlist, security/threat_intel, voice/voice_to_text, payment_engine) that do not validate URLs against private/internal IP ranges before fetching.
4. The WORM audit trail service updates rows after INSERT to append `worm_hash`, violating the immutable Write-Once-Read-Many principle.
5. CAPTCHA verification is silently skipped when `TURNSTILE_SECRET_KEY` is not configured, disabling bot protection on all public auth endpoints.
6. MFA is not enforced for admin/employee roles — the architecture test only checks for the existence of MFA-related code, not actual enforcement.

### Solution(s)
1. Encrypt all payment gateway credentials with AES-256-GCM before database storage; migrate columns to `EncryptedString` type.
2. Replace all f-string SQL with parameterized queries using `sa.text()` and bound parameters.
3. Wrap all outbound HTTP calls with `require_safe_url()` from `infrastructure/security/url_security.py`.
4. Compute WORM chain hash before INSERT and include it in the initial row; remove post-INSERT UPDATE.
5. Make CAPTCHA mandatory in production; fail closed when secret key is missing.
6. Enforce MFA for all admin and employee accounts at the authentication layer.

### Suggestion(s)
1. Add CI lint rule to prevent `public_router` naming for admin-protected endpoints.
2. Remove all `_tmp_*.py` debug scripts from `backend/` root per Law 27.
3. Change CORS default from localhost to empty string to prevent accidental exposure.
4. Add architecture test that verifies all public auth endpoints have CAPTCHA dependency.
