## Over all

### Problem(s)
1. **Structural law violations**: Two extra top-level packages exist (`modules/finance/` as a 6th module, `domains/payments/` as a 17th domain) that violate Laws 12 and 13.
2. **Systemic direct-service imports in routers**: At least 18 router files across modules/admin, modules/customer, modules/supplier, modules/logistics, modules/employee import directly from `domains/*/services/*` instead of through `ports.py`, violating Law 3.
3. **Middleware dependency violations**: `middleware/dependencies/auth.py` imports from `domains.accounts.services.auth.security_dependencies` and `middleware/dependencies/country_detection.py` imports from `providers.geography.ip`, violating Law 1's middleware → {rbac, infrastructure} rule.
4. **Dead code at backend root**: 91 temporary/debug files (`health_test_*.py`, `_tmp_*.py`, `_audit_boot_check.py`) plus outdated runner scripts (`run_tests.ps1`, `run_tests.sh`) violate Law 27 and the project constraint on outdated root runners.
5. **Ports.py anti-patterns**: `domains/finance/ports.py` uses wildcard imports and a service-locator `_LAZY_SERVICE_EXPORTS` with ~70 entries, defeating the purpose of a thin READ surface.
6. **Stub event subscribers**: `domains/finance/subscribers.py` listeners are stub implementations that only log, with no actual cross-domain writes.
7. **Unregistered router file**: `modules/finance/routers/cash_management.py` defines a router but has no `@router.*` decorators and is not loaded by `main.py:_load_routers()`.

### Solution(s)
1. **Delete `modules/finance/`** and move any legitimate routes into `modules/admin/routers/finance.py` (already exists and is loaded).
2. **Delete `domains/payments/`** and consolidate payment logic into `providers/payments/` (SDK adapters) and `domains/finance/services/payments/` (orchestration).
3. **Delete 91 temp/debug files** from backend root and delete `run_tests.ps1`/`run_tests.sh`.
4. **Add missing functions to each domain's `ports.py`** and update all module routers to import from `ports.py` instead of `services/`.
5. **Move auth dependencies** from `domains.accounts.services.auth.security_dependencies` to `infrastructure/security/dependencies.py` and update `middleware/dependencies/auth.py` to import from there.
6. **Wrap provider call** in `middleware/dependencies/country_detection.py` with an `infrastructure/` adapter.
7. **Replace wildcard import** in `domains/finance/ports.py:595` with explicit named imports.
8. **Replace `_LAZY_SERVICE_EXPORTS`** in `domains/finance/ports.py` with explicit thin read-wrapper functions.
9. **Implement actual cross-domain write logic** in `domains/finance/subscribers.py` (commission accrual, settlement posting).

### Suggestion(s)
1. Add `import-linter` contracts to `tests/architecture/` to enforce Law 1 (import direction) and Law 3 (ports-only reads) in CI.
2. Add a pre-commit hook or CI check that fails when `health_test_*.py`, `_tmp_*.py`, or root runner scripts exist.
3. Add a `ports_coverage` test that verifies every function imported by a module router from a domain is exposed via that domain's `ports.py`.
