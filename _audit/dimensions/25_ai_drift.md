## Overall

### Problem(s)
1. `frontend/web_app/src/lib/api/client.ts:109` has a `ReferenceError` where `method` is used before declaration, breaking ALL frontend API calls.
2. `backend/modules/admin/routers/orders.py` is mislabeled as the admin orders router but contains only campaign/email routes from the comms domain; NO order management endpoints exist, breaking the admin order management UI completely.
3. `backend/modules/customer/routers/orders.py:131` carries an "AUTO-GENERATED — DO NOT EDIT MANUALLY" warning but the majority of the file is hand-written code, creating maintenance confusion.
4. 18 instances of raw `detail="Internal server error"` across 9 router files bypass the RFC 7807 global error handler, creating inconsistent error shapes.
5. 15 instances of raw `detail="Not authenticated"` across 7 files use inconsistent status code patterns and bypass the global error handler.
6. `backend/modules/admin/routers/permissions.py` gates permissions management with `accounts.permissions.manage` instead of a dedicated `permissions.manage` atom, creating namespace confusion.
7. `backend/modules/admin/routers/orders.py:76` registers a health endpoint at `/admin_orders_routes/health` which doesn't match the router's `/api/v1/admin/orders` prefix.
8. `backend/modules/customer/routers/accounts.py:60` uses absolute route paths while all other routers use prefix + relative paths, creating an inconsistent routing pattern.
9. `backend/modules/admin/routers/orders.py` gates comms-domain campaign routes with orders-domain feature atoms (`orders.list`, `orders.create`, etc.), creating feature gating drift.
10. `backend/modules/customer/routers/promotions.py:121` uses inconsistent nesting (`/coupons/{id}` for delete vs `/` for create/list), a copy-paste artifact.

### Solution(s)
1. Move `const method = ...` before the `console.log` at `client.ts:109` or remove the debug log.
2. Move campaign routes from `admin/routers/orders.py` to `admin/routers/comms.py`; create proper order management endpoints under `/api/v1/admin/orders`.
3. Remove the "AUTO-GENERATED — DO NOT EDIT MANUALLY" comment from `customer/routers/orders.py` or split the file.
4. Remove raw `HTTPException(status_code=500, detail="Internal server error")` from all router files; rely on the global exception handler.
5. Standardize all 401 error raises to use `status.HTTP_401_UNAUTHORIZED` with a consistent detail string.
6. Rename `accounts.permissions.manage` to `permissions.manage` in both backend router and frontend `FEATURE_CATALOG`.
7. Rename `/admin_orders_routes/health` to `/health` in `admin/routers/orders.py`.
8. Add `prefix="/api/v1/customer"` to `customer/routers/accounts.py` and convert all routes to relative paths.
9. Replace `orders.*` feature atoms with `promotions.campaigns.*` atoms in `admin/routers/orders.py`.
10. Normalize coupon routes in `customer/routers/promotions.py` to consistent `/coupons` nesting.

### Suggestion(s)
1. Add a CI lint rule that flags `ReferenceError`-prone patterns (variable use before declaration) in frontend code.
2. Add an architecture test that asserts each router's declared prefix matches its actual route paths.
3. Add an architecture test that asserts no router file contains raw `detail="Internal server error"` or `detail="Not authenticated"` strings.
4. Add a pre-commit hook that validates feature atom namespaces match the router's domain.
5. Create a shared `AiDriftDetector` script that scans for the 10 drift patterns automatically.
