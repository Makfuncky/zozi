## Over all

### Problem(s)
1. **Structural law violations**: Two extra top-level packages exist (`modules/finance/` as a 6th module, `domains/payments/` as a 17th domain) that violate Laws 12 and 13. A third, `domains/media/`, is structured as a full domain despite canonical stating media has no dedicated domain.
2. **Dependency drift**: 11 dependency mismatches between TECHNOLOGY_STACK.md and `requirements.txt` — including one major version gap (prometheus-fastapi-instrumentator 7→8) and two forbidden packages actively locked (`python-magic`, `psycopg2-binary`).
3. **Frontend version drift**: Six frontend packages (Next.js, framer-motion, Zustand, Zod major, Expo, React Native) are behind canonical versions; Zod is on a major version gap (3.x vs 4.x required).
4. **Config drift**: `config.py` defaults `DEFAULT_COUNTRY` to `AE` (canonical: `US`) and types monetary fields (`vat_rate`, `zozi_commission_rate`) as `float`, violating Law 19.
5. **Package/import mismatch**: `slowapi`/`limits` replace canonical `fastapi-limiter-valkey` in requirements; `fastapi-limiter-valkey` is imported in production but absent from pinned dependencies; root `package.json` uses `npm run` despite pnpm-only mandate.
6. **Dev environment drift**: Dev Dockerfile uses Python 3.11 (canonical: 3.13); dev compose uses Postgres 18 (canonical: 16); dev Dockerfile runs Uvicorn directly without Gunicorn.
7. **Frontend routing contradiction**: Next.js rewrites expose standalone `/hr/*` prefix but no canonical `hr` module exists; duplicate `logistics-partner`/`logistics-partners` route directories.

### Solution(s)
1. Delete `modules/finance/`, `domains/payments/`, and `domains/media/` (or promote `media` as 16th canonical domain). Move finance routes to `modules/admin/routers/finance.py`.
2. Align all dependencies in `requirements.txt` to TECHNOLOGY_STACK.md: bump FastAPI, Alembic, pydantic-settings, prometheus-fastapi-instrumentator, sentry-sdk, stripe, SQLAlchemy; add `uvloop`, `httptools`, `pybreaker`, `fastapi-limiter-valkey`; remove `slowapi`, `limits`, `python-magic`, `psycopg2-binary`, `pytz`, `tzlocal`, `requests`.
3. Bump frontend packages: Next.js to 16.3.5, framer-motion to 13.2.0+, Zustand to 5.0.14, Zod to 4.3.6 (or update docs), Expo to 57.0.20+, React Native to 0.86.3, React to 19.2.8.
4. Fix `config.py`: change `DEFAULT_COUNTRY` to `US`; change `vat_rate` and `zozi_commission_rate` to `Decimal`.
5. Replace `slowapi`/`limits` with `fastapi-limiter-valkey` in requirements.txt.
6. Fix dev environment: update Dockerfile to `python:3.13-slim`; update compose to `postgres:16-alpine`; add Gunicorn-based dev CMD.
7. Fix frontend routing: remove `/hr/:path*` rewrite; replace with `/employee/hr/:path*` or remove standalone HR route; delete duplicate `logistics-partners` directory.

3. Add an import-linter contract to `tests/architecture/` enforcing the 5-module and 15-domain law (fail if extra top-level packages appear under `modules/` or `domains/`).
