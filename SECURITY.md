# Security Policy

## Reporting a Vulnerability

We take the security of the ZOZI platform seriously. If you discover a security vulnerability, please report it privately.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please send a description of the issue to our security team at security@zozi.com. Include as much detail as possible, including:

- Type of vulnerability
- Steps to reproduce
- Affected versions
- Potential impact

We will acknowledge receipt within 48 hours and provide a timeline for resolution.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Disclosure Policy

We follow a 90-day disclosure timeline from the time a fix is released.
